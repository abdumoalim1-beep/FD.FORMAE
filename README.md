# FORMA — Landing Page

صفحة هبوط لـ FORMA، نظام مستندات ذكي يرفع القوالب والبيانات مرة واحدة ثم ينشئ المستندات ويحدّثها تلقائيًا بناءً على الطلب.

هذه الصفحة مبنية بـ HTML/CSS/JS خالص (بدون أي أطر عمل أو أدوات بناء)، بلغة عربية واتجاه RTL كامل.

## البنية

```
index.html      الصفحة الرئيسية
css/styles.css  التنسيقات
js/main.js      التفاعلات (أسئلة شائعة قابلة للطي، نموذج قائمة الانتظار)
assets/         الأصول (أيقونة الموقع)
```

## التشغيل محليًا

لا حاجة لأي تثبيت. يكفي فتح `index.html` مباشرة في المتصفح، أو تشغيل خادم محلي بسيط:

```
python3 -m http.server 8080
```

ثم زيارة `http://localhost:8080`.
